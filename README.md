## How I Work

I like building software from first principles, especially when existing abstractions get in the way.

Most of my projects start as experiments: a problem I want to understand, a tool I wish existed, or an idea that is easier to test by building it.

I believe open source is more than publishing code. It is a way of making ideas executable, inspectable, reusable, and available to everyone.
